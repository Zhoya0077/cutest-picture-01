# Strawberry-Hat Penguin Chick

A chubby baby penguin chick with huge sparkling eyes and rosy blush cheeks tilts its head under an oversized strawberry hat. The chick stands on soft pastel clouds, surrounded by floating hearts and tiny sparkles.

The picture is built from soft round shapes: a plump round body, big bright eyes, and small clumsy flippers. The strawberry hat is the one charm touch that makes the chick feel dressed up for a sunny day. Gentle pink and mint tones keep the whole scene warm and sweet, and the big-eyed face still reads clearly when viewed small.

## Running the entry

Run the program from the repository root with python3 main.py.

The program copies entry.png into the output directory given by MAKEFUN_OUTPUT_DIR, or /output by default. It uses only the Python standard library and needs no network access.
